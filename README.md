# LotPulse Radar

Create a sleek, mobile-first web-app interface for 'Project LotPulse,' a predictive parking radar specifically for UTM students. The UI must be modern, functional, and 'dark mode by default,' prioritizing ease of use and immediate action,specifically avoiding anything 'old school' or administrative.

The main dashboard view should feature:

A prominent 'Hybrid Engine' display for 'LOT P9.' This needs a dual metric visualization:

Live Status: An illuminated indicator reading, 'CLEAR' (e.g., green), paired with 'Last Spot: 3h.'

AI Threat Level: A color-coded gauge (e.g., orange/red) reading, 'THREAT LEVEL: 85%.' This section must include predictive text like, 'High patrol prob: Mon 1PM–3PM[cite: 1],' or 'Predictive model analyzing trends.'

The Massive 'SPOTTED' Action Button. This needs to be the largest, most visually distinct element—a glowing,tactile button (maybe with a subtle animation or electric blue border) that says, 'I SPOTTED AN ENFORCER!'or simply, 'SPOTTED (P9)!' Tapping this should trigger a simulated alert flow.

The 'CLOUT SYSTEM' Gamification Tab. A small leaderboard module on the side, showing 'WEEKLY TOP SCOUTS' with student usernames and scores (e.g., 'UofT_Driver: 450 pts'). This visually represents the competitive incentive to report enforcers.

Just-In-Time (JIT) Integration. A small shortcut button near the P9 status reading, 'Pay 30min (JIT)' or 'Direct Payment Link[cite: 1],' simulating the deep-link functionality for imminent tickets.

Secondary Lots List. Below the P9 focus, include a condensed list of other lots (P4, P8, Inner Circle) showing only their summarized 'AI Threat Level' (e.g., P8: 30% Threat).

The overall design aesthetic must look like a premium, specialized utility tool—utilizing high-contrast typography, subtle gradients, and glowing accents to indicate real-time 'radar' status, perfectly suited for a tech-savvy student body.
